## 🌍 اللغة العربية / Arabic

أداة ذكية وسلسة تتيح لك تثبيت ملفات الـ **PKG** على جهاز الـ **PS4** مباشرة عبر شبكة الإنترنت والاتصال المحلي. تغنيك هذه الأداة تماماً عن عناء نقل الملفات الضخمة إلى الفلاشات أو وحدات التخزين الخارجية وتنسيقها.

### ✨ المميزات الرئيسية
* **إرسال مباشر**: يقوم جهاز الكمبيوتر بإرسال ملف الـ PKG مباشرة إلى عنوان الـ IP الخاص بجهاز الـ PS4.
* **حل مشكلة المساحة**: يمكنك إرسال الملف مباشرة من رابط إنترنت ينتهي بامتداد `.pkg` دون الحاجة لتحميله أولاً على جهاز الكمبيوتر أو الفلاشة.
* **سهولة الاستخدام**: اختصار خطوات التثبيت وتوفير الوقت والجهد.

### 🚀 طريقة التثبيت والاستخدام
1. **تشغيل الأداة**: قم بتشغيل أداة الـ PKG المرفقة على جهاز الكمبيوتر الخاص بك.
2. **تجهيز الـ PS4**: يتم حفظ الملفات تلقائياً في المسار التالي داخل جهاز البلايستيشن: `data/pkgdrop`.
3. **تفعيل خيار التثبيت**:
   * توجه إلى إعدادات جولد هين (**GoldHEN Debug Settings**).
   * قم بتغيير مصدر تثبيت الحزم (**Package Install**) من `USB` إلى `All`.
   * انتقل إلى **Package Installer** وسوف تظهر لك جميع الملفات جاهزة للتثبيت.

⚠️ **تنويه هام للمساحة**: يُنصح بشدة بحذف ملفات الـ PKG بعد اكتمال تثبيتها حتى لا تستهلك مساحة التخزين الداخلية. يمكنك القيام بذلك بسهولة عن طريق تثبيت أي تطبيق لمستكشف ملفات النظام (System File Explorer) على الـ PS4 وحذفها من مسار `data/pkgdrop`.

## 🌍 English / الإنجليزية

A simple, seamless online tool designed for downloading and installing **PKG** files directly onto your **PS4**. This tool streamlines the process by eliminating the hassle of formatting and transferring large files via USB drives.

### ✨ Key Features
* **Direct Transfer**: Your PC sends the PKG file directly to your PS4's IP address.
* **Storage Solution**: Eliminates storage issues on your computer or USB drive by allowing you to transfer files directly from a remote URL ending in `.pkg`.
* **Seamless Process**: Saves time and automates the package delivery efficiently.

### 🚀 How to Install & Use
1. **Run the Tool**: Launch the provided PKG tool on your computer.
2. **PS4 Directory**: The transferred PKG files are automatically saved to the following directory on your PS4: `data/pkgdrop`.
3. **Enable Package Installation**:
   * Navigate to **GoldHEN Debug Settings** on your PS4.
   * Change the **Package Install** source from `USB` to `All`.
   * Open the **Package Installer**, and you will find your files ready to install.

⚠️ **Important Storage Notice**: It is highly recommended to delete the PKG files after successful installation to free up storage space. You can easily do this by using any system file explorer app on your PS4 to navigate to `data/pkgdrop` and remove the files.
