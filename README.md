PKG files are saved to the data/pkgdrop directory on the PS4. To install them, go to GoldHEN Debug Settings, change the "Package Install" source from USB to "All," and you will see them in the Package Installer. It is recommended to delete the files after installation to free up space; you can do this by downloading any system file explorer and deleting them from there. 👍
